New code written by Future Digital Plus. There is no upstream and no third-party code in this module.

## Purpose

A thin facade that wires the other modules together so a screen starts with one component: install the design
system base styles and a theme, the `fdp-input-touch` class and the safe area on a `UIDocument` root, and two fade
helpers over the Animation module. Added only where it adds real value; everything else is called on the modules directly.
Guide: `../../Documentation~/UIKit/README.md`.

## Design decisions

- **Base stylesheet on the panel root.** On Unity 6000.3.25f1 the design system's `:root` tokens outrank a class-scoped
  theme on the same element or on an ancestor of the element holding the base sheet, whatever the sheet order
  (measured in a PlayMode experiment: base and theme on the document root gave the dark colour; base on the panel root
  and theme on the document root gave the light colour). The installer therefore puts the base sheet on `root.parent`
  (reference counted per holder, because several documents can share a panel) and the theme on the root.
  An unattached root gets the sheet on itself and moves it on `AttachToPanelEvent`.
- **Safe area uses the panel's size**, not the document root's: a root without content can be 0 high.
- **The facade steps aside for a shell.** When an element with the class `fdp-shell` (the Foundation shell's root) appears under the document root, the installer gives its safe-area padding back and stops writing `fdp-input-touch`: the shell pads its own bars, dialogs and toasts, and the input profile owns the touch class. The only link between the modules is that class name. The ready-made host that builds a shell lives in the separate `Bootstrap` assembly, so this assembly keeps referencing DesignSystem and Animation only.
- **The device safe area is for screen panels.** The default `SafeAreaSource` returns the whole screen for a panel that renders into a `RenderTexture`, a world-space panel or a panel on another display (same rule as `UiPanelKinds` in Foundation, repeated here because the facade must not reference Foundation); a source the caller assigns is applied to every panel.
- **Polling every 500 ms** for the safe area (rotation, fold) instead of a platform callback; cheap and portable.
- **No new asmdef for the editor**: there is no editor code.
